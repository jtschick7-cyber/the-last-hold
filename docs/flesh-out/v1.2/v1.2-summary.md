# v1.2 "Sounds of the Frontier" — flesh-out summary (2026-10-23)

For the owner. Plain language. Decisions are D519–D528 (all start as Proposed; D528 is your yes in the first message of the Claude Code thread).

## What v1.2 is

Seven short sound effects for 15 moments, **off by default**, with one **Sound On / Off** switch in More ▸ Settings. Sound is a layer on top: it changes **no game number, rule or save** (save stays version 12, rules version stays 5, every golden fight and simulator report is unchanged).

| Sound | When it plays |
|---|---|
| Build | You buy a building level or plot, or build a new building |
| Launch | A contract is launched |
| Place | A piece is placed in Arrange Hold (a finished move or swap) |
| Win | A contract is won; a Delve floor is cleared |
| Lose | A contract is lost; a Delve run is lost |
| Fanfare | The Hold's own Rank-up; hunter rank-up; Great Beast milestone; Great Beast kill; Legendary hunter unlocked; Delve guardian beaten |
| Nightfall | The Long Night arrives |

**Silent on purpose, and anything not in the table is silent:** taps and tab changes; anything that happened while you were away, was caught up on return, or happened while the app was hidden; the Last Stand's start and result; Leave run; attempts that earn nothing; the Remembering and the endings; Auto-arrange, Clear to tray, Move to tray; recruiting and Stores.

## Why these choices

- **Off by default, one switch, no volume.** Simple, and your phone's volume and silent switch already do the rest. The silent switch is respected and never worked around.
- **A sound that can't play right now is skipped, never saved up.** On iPhone, sound starts only after a tap, and stops after a call or a lock; the next tap brings it back. Nothing plays while the app is hidden.
- **Web Audio and small mono MP3 files.** No new runtime dependency. They are cached like the rest, so sound works offline.
- **You pick the sounds by ear.** I can't hear. An audition page (preview build only) will offer about 5 clips per sound, about 35 in all, from four Kenney packs (all CC0). About 15 minutes of listening.

## Red-team pass (mine, then an outside review you sent): what could go wrong, and how it is covered

| Risk | Cover |
|---|---|
| iPhone won't start or resume sound (tap rule, calls, locks, silent switch) | Unlock on the switch tap or first tap; resume on the next tap; skip, never queue; Q55 and the playtest on your phone (CI can't prove this) |
| Sounds missing offline | SF.7 checks the cache pattern for `.mp3` and fetches a sound while offline; stop and ask if it can't be cached |
| Over 600 KB | Measured before and after (SF.9, SF.12); budget formula; stop and ask, never change the row |
| Candidates leak into the live app | A test fails if any candidate or the audition page reaches the live build or the size count |
| Saves | No save change; `sound` lives in the settings key; Reset keeps it; Paste / Load / Restore never touch it |
| Core touched by mistake | Sound module on the non-coupling lint list; a cue needing a core change means stop and ask |
| Tests weakened | Only the listed edits (D525, D526); everything else stops and asks; all 55 rows and 176 of 176 reports unchanged |
| Noisy or repeated sounds | One per command; strongest wins in 300 ms; first appearance only; Skip plays one |
| New layout problems | Sound row goes into the 44 px, width, Largest-text, motion and contrast sweeps; no new tap, sheet or animation; check-in still 15 taps or fewer |
| Test save goes stale 2026-10-26 | Now task 1, with an exact field list and a proof script |
| Audition can't reach your phone or plays OGG | Candidates converted to MP3, committed, copied into the preview build only |
| Unclear when a sound plays | Each moment has one named trigger; anything not listed is silent; Claude Code stops and asks if a trigger isn't a single UI event |
| Test fake hides real problems | The fake replaces only the output; all readiness rules still run |
| Slow CI | `npm run check` warns at 90 s, fails at 120 s (D512); e2e limit 15 min (D513); SF.12 re-measures |
| No audio converter in the container | Q56: install one, or you convert; a new dev dependency only with your yes |
| Repo grows by the zips | Stated in D524 (4); they stay in git history |
| WebKit can't decode MP3 in CI | SF.7 says so and leaves it to your phone (Q55) |
