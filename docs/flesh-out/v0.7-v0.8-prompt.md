### Rules for you (the project's rules, from CLAUDE.md; they bind this session too)
- **Ask me with options and a recommendation. Never choose silently.** If the documents don't answer a design question, ask. Confirm assumptions. Ask 3 to 4 questions at a time, in plain text with lettered options (I will answer with letters, e.g. "1a 2c"). Don't use any form-style question tool; I declined it once.
- **Plain language, no code.** Explain what the player sees and does.
- **Everything numeric is a named constant** under its GDD §7 key, marked `tunable` or `locked` (the new keys go in a new GDD §7.9). Balance fixes change tunable constants only, never formulas. I decide which constants are locked.
- **Determinism:** same seed and same commands give the same state in every browser engine. Every player action is a command; time passes only by advancing. The UI never computes game rules. Combat changes bump `rulesVersion`; the seeded golden fights are locked fixtures.
- **Saves:** never change the schema without a migration, a fixture of a real old save, and a round-trip test.
- **Originality:** all content is original; every new proper noun (patron blessings, guardians, Act IV characters, places) must not collide with the influences listed in GDD §2.3 (Witcher, Skyrim, Warcraft, Warhammer 40K, and so on). You may not be able to search; list every new proper noun clearly so Claude Code can run the collision search, and prefer plainly folk-like or invented names. Assets are CC0 only.
- **Honesty in the game:** every visible number with a formula has a breakdown built by the same function that builds the number.
- **The suite is touchy:** a milestone must stay inside the simulator's 5-minute budget, and the full simulator suite has many near-edge rows (a tiny number change can flip one). Prefer designs that don't add fragile new checks; every new check needs a target row I approve.
- **Decisions format:** rows for `docs/decisions.md`: `| D<next> | YYYY-MM-DD | <what was decided, specific enough to act on> | Owner | Decided |`, numbered from **D244**. A row is `Decided` only after I've said so; anything you propose and I haven't confirmed is `Proposed`. Never edit or reuse old rows. Questions I haven't answered go to `docs/questions.md` format, numbered from **Q20**.
- Don't build ahead of the milestone, and don't change anything about v0.6 or earlier except to fix a documented drift.
