## How to download and upload (about 10 minutes, easiest on a computer)

1. **Download.** Open each page above. Click **Continue without donating** (or donate if you like), then download the zip. You'll have four `.zip` files.
2. **Open the repository** on GitHub: https://github.com/jtschick7-cyber/the-last-hold
3. **Switch to the milestone branch first.** Click the branch button near the top left (it says `main`) and pick **`milestone/v1.2`**. Check that the button now says `milestone/v1.2` before you go on.
4. **Open the folder `art-src/packs/audio/`**, then click **Add file → Upload files**.
5. **Drag all four zip files** onto the page. **Do not unzip them.** GitHub's web upload takes at most 100 files at a time, and Impact Sounds alone has about 130, so zips are the way.
6. Under "Commit changes", keep **"Commit directly to the `milestone/v1.2` branch"** selected and click **Commit changes**.
7. Tell Claude Code the zips are uploaded.

**If a zip is over GitHub's 25 MB limit** for web upload, GitHub will refuse it. Don't split it; tell Claude Code which one, and we'll use another route.

The zips stay in the repository's history for good, so the repository grows by their size. That was agreed in D524.
